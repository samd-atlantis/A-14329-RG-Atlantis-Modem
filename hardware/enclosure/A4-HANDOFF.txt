MAINS CONNECTIONS
Three DORABO DB142V-5.08-3P-GN / JLCPCB C2898700 push-in terminal blocks:
CN1 (schematic source originally J1) = AC INPUT.
J15 = OUTPUT 1. J16 = OUTPUT 2.
Pin 1 = L / AC_L_IN; pin 2 = N / AC_N; pin 3 = PE / CHASSIS_PE.
Both outputs are directly in parallel with input. They are not switched or
individually fused. F1 remains a separate 1 A branch fuse for PS1 only.
Design target: 120 VAC, 10 A TOTAL through the unit, shared by external loads and
the gateway supply. Installation requires suitable upstream protection no greater
than 10 A; the gateway branch fuse does not protect the parallel output feeds.
PE is continuous and is never fused or switched. Protective-earth fault-current
capability and bonding tests remain release requirements.

Manufacturer states UL/CUL 300 V, 10 A, AWG24–14 for this terminal family. Thus it
accepts the requested AWG14–18 conductors. Strip length is 10 mm per manufacturer.
Use conductor sizing and termination appropriate to the actual load and applicable
installation requirements; accepting 18 AWG does not make every 18 AWG installation
suitable for 10 A. The 10 A feed is provisionally planned for 14 AWG copper.
JLCPCB stock observed in EasyEDA: 1,027 terminals (150 needed for 50 boards).

ROUTING
Existing 4-layer, 1 oz outer-copper stack retained. AC_L_IN and AC_N now have a
manual high-current routing rule: 8 mm minimum, 10 mm preferred trunk width.
These are provisional design constraints, not a verified ampacity rating. Local
terminal fanout, unequal current sharing, thermal rise, copper thickness, PE path,
fuse coordination and fault conditions require engineering review and testing.
Do not auto-route the mains trunks using thin default signal tracks.
Primary-to-secondary net clearance remains 8 mm, extended to the new USB nets.
Pour-exclusion corridors added around the primary/secondary boundary. Keep the
low-voltage reference plane continuous locally, without crossing mains isolation.
The added USB console pair uses USB90_CALC_PENDING; all impedance geometry remains
subject to fabricator stackup confirmation.

USB-C PROGRAMMING
J14 / FG-ST-C-16P-LS-SMTD-6.5 / C51912230 -> ESD U19 -> CH340C U16 -> UART buffer U18 ->
router UART0. Both CC pins have separate 5.1k Rd resistors. VBUS feeds a separate
ME6211 3.3 V regulator U17 for the USB bridge; it does not feed the gateway rails.
CH340 VCC and V3 both use that 3.3 V rail. Buffer outputs are disabled when USB
is absent; Ioff prevents back-powering when the router supply is absent.
Existing reset and recovery-request buttons remain. Do not simultaneously drive
the router RX fixture pad and USB console. J7 source is H1 in native PCB annotation.
Firmware source now includes lrzsz serial file-transfer support. See
../../firmware/USB-C-service.txt for the intended programming procedure and limits.
This is not a native USB DFU boot interface. Modem firmware service remains on J12.
