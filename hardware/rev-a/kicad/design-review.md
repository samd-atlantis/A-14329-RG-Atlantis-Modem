# Rev A1 engineering review — native KiCad schematic capture

This supersedes the functional schematic drawings for electrical connectivity. It is an engineering review package, **not a released PCB design**. Wi-Fi and Bluetooth remain fitted; LoRa is omitted.

Open `walchem_gateway.kicad_pro` in KiCad 9 or later. The root schematic contains seven child sheets. Symbols are embedded and also supplied in `Gateway.kicad_sym`; selected footprints are local. No KiCad installation or Python packages are needed to open the supplied project once KiCad is installed.

## What is captured

- Isolated 120 VAC to 5 V supply, fuse location and separate primary / secondary nets.
- Independent TPS62132 3.3 V router and modem rails, inductors, input/output capacitors and soft start. Fixed-output FB/DEF/FSW connections and exposed-pad ground are mapped.
- All 56 Hi-Link module signal/power pads, four 10/100 MDI channels, USB host, dedicated UART1, UART0 console and I2C.
- MCP23008 **18-pin SOIC** management expander at I2C address 0x20. The SSOP version is 20 pins and must not be substituted against this symbol/footprint.
- All 52 modem connector positions, including Quectel-specific SIM pins, USB D+/D-, reset, all supply contacts and grounds. Reserved pins remain open. No PCIe data signals are implied.
- USB switch disconnects the modem data pair when MODEM_OFF is asserted; open-drain reset avoids a host pull-up into an unpowered modem.
- Four-pole TS3A44159 SIM selector switches VCC, CLK, RESET and IO. Default low selects the physical SIM. Physical SIM ESD is referenced to its switched supply. The eUICC mapping is specifically the ST4SIM-200M VFDFPN8/MFF2 family, not a consumer QR-code provisioning promise.
- Ai-WB2-13 Wi-Fi/BLE module, switched auxiliary rail, power-off-safe UART buffers, enable pull-up and TTL service header. Default-NC reset pin 15 is left open. GPIO5 service button and its pull resistor are DNP until the programming/boot procedure is confirmed.

Wi-Fi controller networking uses the **router module's native Wi-Fi**. Ai-WB2-13 provides the additional BLE / Wi-Fi provisioning application. Its UART is not treated as a transparent IP/Ethernet bridge. Firmware must implement setup commands, configuration transfer, radio coexistence and access controls. The board deliberately contains two 2.4 GHz radio-capable modules; channel planning, antenna separation and simultaneous operation require bench testing.

## Footprints and unresolved physical choices

The project-local HLK footprint is derived from Hi-Link's original Altium PcbLib, converted through KiCad. Vendor signal pads 1–56 are retained. Vendor thermal pads 57/58 are renamed EP3/EP2 in the project. The manual shows **three** grounded thermal lands while the library supplies only two; the central EP1 5×5 mm land is added from the manual drawing. This conflict is explicitly unresolved: compare the exact purchased module revision, library and recommended land pattern before layout release. The original unmodified converted footprint `7628N` is also supplied for comparison.

The Ai-WB2-13 footprint is transcribed from the published 18×20 mm outline and 1.5 mm pitch. Land extension and soldering allowance are provisional. Its antenna region is drawn on Dwgs.User as a placement reminder; this is **not an enforced copper keepout**. The PCB layout must implement the actual all-layer antenna keepout and enclosure RF window.

The following are deliberately left without footprints, so an unverified generic package cannot be mistaken for a selected part:

| Reference | Remaining work |
|---|---|
| J1 | Select mains-rated touch-safe terminal, wire range, retention and enclosure access |
| F1 | Select fuse/holder, breaking capacity and time-current characteristic against supply inrush and available fault current |
| J8 | Select exact Mini PCIe socket height, key, retention and module standoff; map the supplier drawing to physical contacts 1–52 |
| J9 | Select actual nano-SIM socket; translate ISO C1/C2/C3/C5/C6/C7 into its physical pad numbering and add detect/shell contacts |
| U8 | Create/select the exact TI RSE-10 2×1.5 mm land pattern from the mechanical drawing; do not use a generic 1.4×1.8 mm UQFN |
| U11 | Select provider-provisioned eUICC ordering code and validate its MFF2 land pattern and profile-management standard |

These are measurable layout gates, not hidden ERC exclusions. ERC does not require every symbol to have a footprint.

## Manufacturer ambiguities that remain

1. Ai-WB2-13 pins 13/18 are called NC in the pin diagram but described as Ground in the table. They are left open with explicit NC markers. Obtain exact-revision clarification before committing the PCB. Pin 15 is NC by default and is not used as reset.
2. Hi-Link thermal lands differ between the library and manual as described above. Module revision must be matched to purchase order and incoming inspection.
3. Confirm the exact EG25-GL Mini PCIe SKU's latest controlled hardware guide, USB operating mode, SIM voltages, PERST timing and carrier approvals. The pin table is captured but a public mirror is not a controlled vendor release.

## Firmware contract for the captured hardware

MCP23008 address pins A0/A1/A2 are grounded, address 0x20. GPIOs power up as inputs. External pulls give deterministic initial states:

| Port | Net | Low / reset default | High |
|---|---|---|---|
| GP0 / pin10 | SIM_SELECT | Physical SIM | eUICC |
| GP1 / pin11 | MODEM_OFF | Modem rail enabled; USB switch connected | USB isolated and modem rail disabled |
| GP2 / pin12 | MODEM_RESET_REQ | Reset released | Open-drain PERST asserted |
| GP3 / pin13 | WIFI_AUX_EN | Ai-WB2-13 auxiliary rail off | Auxiliary rail on |
| GP4 / pin14 | WIFI_BUF_DISABLE | Driven low only when firmware is ready | UART buffers disabled; pull-up on auxiliary rail provides startup default |

Write safe output-latch values before changing IODIR. Disable auxiliary UART buffers before external programming. Router UART1 TX/RX must not have boot-time external drive. After enable, Ai-WB2 RX connects through U13 to router TX, and Ai-WB2 TX connects through U13 to router RX.

For SIM change: detach gracefully; assert MODEM_OFF; wait for modem and SIM rails to discharge; change SIM_SELECT; wait for switch settling; release MODEM_OFF; use the modem's documented boot/attach sequence. Do not switch a live SIM session. Hardware implements one active subscription, not dual simultaneous cellular connectivity.

## Validation and release boundary

Read `exports/verification.json` for the final measured check counts. KiCad ERC is run with the standard project rule severities and no per-violation exclusions. Power flags on fused AC and the two SIM rails annotate legitimate external/passive power paths; they do not represent additional power supplies. The netlist comparison checks all connected captured pins and an additional set of critical USB/UART/SIM mappings. Supplied footprint pad numbers are checked independently.

The previous numerical load-step sweep is still an assumption-driven charge-deficit study. It is **not** vendor-model SPICE, regulator stability verification, or proof that the modem will remain powered during attach/transmit. The selected nominal 116uF modem bank must be checked for effective capacitance, tolerance, LC stability, startup inrush and actual modem load steps. Do not use the old 470–3300uF sweep as approved BOM values.

Before board layout is released: close the six unassigned physical choices, reconcile the module-document ambiguities, choose enclosure/antenna arrangement, finish mains protection/spacing/earth review and assign stackup-dependent routing constraints. USB target 90Ω differential and Ethernet MDI target 100Ω differential require the actual PCB stackup. Keep switch-node loops compact, Kelvin-sense VOS and keep antennas/USB/MDI away from the primary and switching nodes. No numeric mains creepage/clearance has been invented without the environmental assumptions needed to calculate it.

Before manufacturing: qualify modem power cycling and weak-signal transmission; verify four LAN links, Wi-Fi controller access and BLE setup; test both SIM paths and provider provisioning; complete thermal, safety, EMC and applicable radio/carrier integration review. A clean ERC does not replace those checks.
