HLK-7628N C209920 memory evidence - 2026-10-29

The chosen 32 MB flash profile is supported by the exact C209920-linked datasheet's
default specification: 32 MB flash and 128 MB DDR2 RAM. This is the expected
configuration, not conclusive evidence of the memory fitted to the ordered lot.

The LCSC C209920 listing links to /datasheet/C209920.pdf. Its embedded manufacturer
PDF is Hi-Link hardware manual V1.0, cover dated 2017-07-06. Printed page 4
(PDF page 7), section 2.2, gives these parameter and note pairs:
  RAM:   DDR2 128 MB; customizable DDR2 64/32 MB.
  Flash: 32 MB; customizable 16/8 MB.
Printed page 2 also depicts alternative memory densities. Neither JLC nor LCSC's
public C209920 attribute table supplies a separate memory-capacity field or a
memory-specific ordering suffix. Thus default support is established, while
first-board flash/RAM, bootloader and partition-map verification remains necessary.
